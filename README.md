# Misi Kata: Pengembaraan Bahasa

Permainan pendidikan RPG ringkas untuk latihan Pemulihan KSSR Bahasa Melayu. Murid mengisi nama, kelas dan tarikh sebelum menjawab 10 soalan pelbagai bentuk. Markah dikira secara automatik dan sijil penyertaan PDPR boleh dicetak.

## Cara menggunakan

Buka `index.html` dalam pelayar web. Permainan ini tidak memerlukan pemasangan atau sambungan internet.
